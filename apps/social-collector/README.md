# Social collector boundary

This component handles interactive or platform-specific social discovery separately from the scheduled public-news updater. It must not open the application database or call database SQL directly. Its output is one JSON object per line following `record.schema.json`, written to `data/inbox/` for the normal import pipeline. The isolated importer checks the required title, allowed platform, HTTPS source URL, and rejects top-level cookie, token, password, session, and raw-HTML fields.

The collector may use an explicitly authorized browser session or platform export. Keep browser profiles and cookies outside this repository and never include them in JSONL records. Preserve the original post URL and Chinese text; English title/content are separate fields. New records remain `unverified` unless a human verification process supports a different status.

Reports can describe any road incident in China; an ADAS claim is optional. Include province, city, event date, and the direct source URL when known. A report's inclusion and community relevance rating do not verify the underlying incident. Xiaohongshu collection uses the official website in an explicitly authorized, read-only browser session; there is no Xiaohongshu web-index feed or page-scraping adapter. Preserve the original note URL and only public evidence visible in the session. Stop on CAPTCHA, throttling, login expiry, or other platform controls. Export resulting leads through this JSONL importer with `verification_status` set to `unverified`.

Run the isolated importer with `npm run vnext:import-social`. It processes only the `manual-platform-exports` inbox source. After a fully successful import, each `.jsonl` input is renamed to `.jsonl.processed` in the same folder so the next daily run reads only new files. The original bytes remain recoverable. The scheduled updater runs with `npm run vnext:update-public` and is configured separately in `public-sources.json`; it discovers direct Weibo URLs through public web indexes. Xiaohongshu is collected separately from the official site and imported through the JSONL path.
